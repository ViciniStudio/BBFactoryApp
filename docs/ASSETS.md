# Assets

## `HeroBurger`

- **Fichier** : `BBFactoryApp/Resources/Assets.xcassets/HeroBurger.imageset/hero-burger.jpg`
- **Dimensions** : 1280 × 1515 px (recadrage du visuel officiel, ratio 0,845)
- **Source** : site officiel B&B FACTORY, galerie `dish.co`
  - URL d'origine : `https://cdn.website.dish.co/media/29/32/8080190/B-B-FACTORY-IMG-1262-jpeg.jpg`
  - visuel : burger B&B FACTORY, frites et garnitures, fond ardoise
- **Intégration** : demandée explicitement par le client pour remplacer l'illustration vectorielle du héros.
- **Droits** : la photographie reste la propriété de B&B FACTORY et de son photographe. L'établissement doit confirmer l'autorisation de diffusion avant une publication sur l'App Store. Pour remplacer le visuel, écraser `hero-burger.jpg` par la photo fournie par le restaurant en conservant le même nom et le même cadrage (ou adapter le `scaledToFill` dans `HomeView.swift`).
